### 1.3 安全体系

| README 描述 | 实际代码 | 状态 | 审计依据 |
|---|---|---|---|
| **Spring Security** | **未使用**。pom.xml 中无 `spring-boot-starter-security` 依赖 | **未实现** | 全局搜索无 `SecurityConfig`、`WebSecurityConfigurerAdapter`、`@EnableWebSecurity` |
| **JWT** | **未使用**。无任何 JWT 库（如 `jjwt`、`nimbus-jose`、`spring-security-oauth2`） | **未实现** | Token 实际实现方式：`CommonUtil.getRandomString(32)` 生成随机字符串 → 存入 MySQL `token` 表 → 1 小时过期。见 `TokenServiceImpl.java` |
| — | **Apache Shiro**（pom.xml 中有 `shiro-spring:1.3.2` 依赖） | **部分实现** | 依赖已引入但代码中未配置 ShiroFilterFactoryChain、Realm 等核心组件，未实际参与鉴权流程 |
| — | 自定义 Token 拦截器（`AuthorizationInterceptor`） | **已实现** | 拦截所有请求（`/**`，排除 `/static/**`），从 HTTP Header `Token` 中提取 token 字符串，查 MySQL `token` 表验证。方法标注 `@IgnoreAuth` 则跳过 |

**实际鉴权流程**:
```
客户端请求 → AuthorizationInterceptor.preHandle()
  → 检查 @IgnoreAuth 注解 → 有则放行
  → 读取 Header "Token" → TokenService.getTokenEntity(token)
    → SELECT * FROM token WHERE token = ? AND expiratedtime > NOW()
  → 成功：设置 Session(userId, role, tableName, username)
  → 失败：返回 401 JSON
```

**安全风险**:
| 风险项 | 说明 | 位置 |
|---|---|---|
| 明文密码 | 用户密码以明文存储和比较，无哈希、无加盐 | `UsersController.login()` / `YonghuController.login()` |
| 硬编码重置密码 | `resetPass` 将密码重置为固定值 `"123456"` | `UsersController.resetPass()` / `YonghuController.resetPass()` |
| Token 无签名 | Token 是随机字符串存 DB，无防篡改机制 | `TokenServiceImpl.generateToken()` |
| 无 HTTPS 强制 | 无 SSL/TLS 配置，Token 明文传输 | `application.yml` |
| 无速率限制 | 登录接口无防暴力破解机制 | 所有 Controller |
| 部分接口 @IgnoreAuth | `/list`、`/detail/{id}` 等前端接口无需鉴权即可访问 | 多个 Controller |

## 四、综合评估

### 4.1 README 可信度总结

| 类别 | 总项数 | 已实现 | 部分实现 | 未实现 | 与README不符 |
|---|---|---|---|---|---|
| 技术栈-后端 | 8 | 2 | 1 | 4 | 1 |
| 技术栈-前端 | 4 | 0 | 0 | 0 | 4（无法审计/不符） |
| 技术栈-基础设施 | 3 | 1 | 1 | 1 | 0 |
| 架构特性 | 6 | 1 | 2 | 3 | 0 |
| **合计** | **21** | **4 (19%)** | **4 (19%)** | **8 (38%)** | **5 (24%)** |

> **结论**: README 中约 62% 的技术栈和架构描述与代码实际不符或完全未实现。README 本质上是一份模板化的营销文案，而非真实的技术说明。

### 4.2 关键风险

1. **安全风险严重**: 明文密码、无签名 Token、无 HTTPS、无速率限制、fastjson 1.2.8 存在已知反序列化漏洞
2. **无缓存层**: 所有请求直接穿透到 MySQL，无法支撑无人超市的高并发场景
3. **无支付网关**: 虽有余额支付逻辑，但缺乏真实的第三方支付（支付宝/微信）集成
4. **数据校验缺失**: 所有入参校验被注释掉，任意数据可直接写入数据库
5. **依赖版本老旧**: Spring Boot 2.2.2（2019 年发布）、MyBatis-Plus 2.3、fastjson 1.2.8 均已过维护期
